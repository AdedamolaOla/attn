# AttnDesignSystem

A reusable SwiftUI package containing attn foundations and product components.

## Overview

The package keeps the app’s visual language separate from feature and service
code. Foundation values mirror the approved Figma system and are exposed through
semantic APIs including AttnColors, AttnSpacing, and AttnMotion.

## Topics

### Foundations

- AttnColors
- AttnTypography
- AttnSpacing
- AttnRadius
- AttnMotion
- AttnHaptics
